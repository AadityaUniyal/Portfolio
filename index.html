Quorum OS

Document intelligence for financial and legal review

Quorum OS turns financial and legal documents into reviewable findings. A seven-agent workflow combines Groq and Gemini inference with deterministic Python Decimal checks and spatial provenance, so a result can be traced back to its source evidence.

Design choice: keep arithmetic deterministic and preserve where each extracted value came from

DarkStori

Operating system for quick-commerce networks

DarkStori models the linked decisions behind a dark-store network: where to open, what demand to expect, how pickers move, and how orders should be dispatched. Its modules include site scoring, demand forecasting, layout optimization, rider batching, and perishables planning.

Algorithms: XGBoost / Prophet forecasting · simulated annealing · 2-Opt · Clarke–Wright batching
One operating view across the site, store, and delivery workflow
Python FastAPI XGBoost React Neon Postgres Redis Optimization

Mini-AWS (MiniCloud)

A local cloud platform built as a modular monolith

MiniCloud recreates core cloud-service workflows on a local machine. The Java 17 and Spring Boot monolith connects IAM policy checks, EC2 lifecycle management, S3 storage, Docker-backed Lambda execution, VPC networking, and CloudWatch-style metrics through a desktop UI, REST API, and CLI.

Architecture: IAM · EC2 · S3 · Lambda · VPC · metrics, with local and container launch paths
S3 events can invoke Lambda workloads; runtime can stream execution logs
Java Spring Boot Java 17 Docker Cloud networking Python CLI
